# Lyric Studio 要求仕様書

2026-11-24 / レビュー案 / [承認・変更管理 #1](https://github.com/sutonomega/lyric-studio/issues/1)

## 目的と利用方法

Windows 11 のブラウザで、入力した日本語歌詞を歌声に同期し、手直しして字幕付きMVを出力する。既存のMP4に字幕を追加する方法と、音楽と静止画からMVを作る方法を提供する。素材、歌詞、解析結果をローカルに保持し、有料APIを必要としない。

## 初期正式版の要求

| ID | 要求 | 受け入れ確認 |
| --- | --- | --- |
| R01 | MP3・WAV、MP4、PNG・JPEG、貼り付け・TXTを読み込む。音声付きMP4、または音声と静止画をプロジェクトの入力にできる。 | それぞれの形式と2つの制作経路で読み込み・再生を確認する。音声トラックのないMP4、非対応コーデック、破損ファイルには原因を表示する。 |
| R02 | 入力歌詞を正とし、行単位で自動同期する。前奏・間奏・後奏、繰り返し、日本語の表記揺れを扱い、根拠の弱い行を示す。ボーカル分離は比較可能で、無効でも検証できる。 | [検証計画](sync-validation.md)のゲートを満たし、出力の表示文言が入力歌詞と一致する。 |
| R03 | 構成タグと空行を字幕から除外する。初期案では、単独行の括弧で囲まれた Verse、Pre-Chorus、Chorus、Bridge、Outro を対象とし、大文字小文字と明示的な番号を許容する。 | 同じタグの繰り返し、タグと歌詞の混在、未知の括弧表現を確認する。未知の行は確認対象に残す。歌詞行の重複は保持し、省略されたサビ本文の自動補完は今後検討する。 |
| R04 | 歌詞・開始終了時刻の編集、追加・削除・分割・結合、タイムライン操作、一括オフセット、再生位置による時刻設定、Undo/Redo。 | 時刻の範囲と順序を検証し、ドラッグや一括操作を1回のUndoで復元できる。未同期行も手動で配置できる。 |
| R05 | ダークテーマの編集画面で、再生・停止、シーク、波形、タイムライン、再生中の行の強調、行選択からのシーク、字幕とデザインの即時プレビュー。 | 楽曲または動画のシークと波形・字幕表示が一致し、編集した時刻とスタイルが更新される。 |
| R06 | 字幕のフォント、サイズ、色、透明度、縁取り、影、文字間隔、行間隔、表示位置、フェードイン・アウトを設定できる。 | 日本語フォントでプレビューと書き出しの位置、改行、フェードを比較し、使用できないフォントを案内する。 |
| R07 | 16:9（1920×1080）と9:16（1080×1920）の焼き込みMP4、SRT、ASSを出力する。 | 2系統の素材×2比率で動画と音声を検査し、日本語字幕を確認する。SRTとASSは別の再生環境で開く。未配置行の扱いを出力前に表示する。 |
| R08 | 新規作成、手動保存、再読み込み、再編集、自動保存、解析キャッシュ。 | 再起動・素材移動・解析中断後に、プロジェクトと編集を復元する。解析設定変更時は必要な段階から更新する。 |
| R09 | Windows 11 x64のローカル運用。CPUで一通り動作し、対応環境ではGPUを選択できる。解析・書き出し中も編集画面が応答し、進捗とキャンセルを提供する。 | CPUと利用可能なNVIDIA GPUで実機確認。初回セットアップ後にオフラインで解析と出力を確認する。キャンセルや失敗で素材と既存出力が壊れない。 |

## 初期正式版以降

1:1（1080×1080）、LRC、部分出力、単語単位同期、カラオケ表示、アニメーション、デザインプリセット、Sound Canvas連携を拡張候補とする。1:1は開発計画の対応比率に含まれるため、初期正式版への繰り上げ可否を #1 で確認する。LRCは開発マイルストーンに従い Phase 6 に置く。

## 開発の判定

Phase 1 は音声入力、分離有無の比較、行同期、JSON・SRT、実曲での精度と修正負担の測定を完了し、Phase 2への移行判定を行う。正式版は R01〜R09 の確認後にリリースをレビューする。
