# 初期版のリリースノート案

対象はWindows 11上で動くローカルWebアプリです。Windows検証と正式リリースレビューは [Issue #15](https://github.com/sutonomega/lyric-studio/issues/15) に記録します。

## 搭載機能

- MP4、またはMP3・WAVとPNG・JPEGから字幕付きMVを作成できます。
- 日本語歌詞を入力し、ローカルの音声認識で行単位の同期候補を作成できます。処理の進捗、キャンセル、未配置、要確認の理由を表示します。
- 追加確認用モデルを設定すると、別モデルと分離ボーカルの音量で確認が必要な行を絞り込めます。同じ画面から対象行を編集し、前後の確認行へ移動できます。
- 波形と字幕タイムライン、字幕の手動編集、Undo/Redo、スタイルとフェードのプレビューを使えます。
- SRT、ASS、字幕焼き込みMP4を保存できます。MP4は横長1920×1080と縦長1080×1920に対応します。
- プロジェクトをローカルに保存し、開き直して編集を続けられます。移動・改名した素材は内容の指紋で再リンクできます。同期結果は同条件の場合に再利用されます。

## 利用時に確認する点

実曲の要確認行は原音を聴いて修正します。自動チェックはモデル間の一致とボーカルの活動を示し、実際の歌唱時刻や修正時間を直接測った数値はありません。

初回の依存ライブラリとモデルの取得が必要です。プロジェクトを再開するときは素材ファイルを再リンクします。ASSを別のPCで使う場合は、同じフォントをインストールしてください。

正式公開の判断と既知の課題は[Windows検証結果](windows-validation.md)に記録します。
