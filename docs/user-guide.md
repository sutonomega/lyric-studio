# Lyric Studio 操作マニュアル

## 素材と歌詞を読み込む

1. 「プロジェクト」で名前を入力します。［新規］で新しい作業を開始し、［開く］で保存済みのプロジェクトを読み込めます。
2. 「動画・音声を選ぶ」で音声付きMP4、MP3またはWAVを選びます。音声を使う場合はPNG・JPEGを背景画像として選べます。
3. 「同期用の歌詞」に歌詞を貼り付けるか、UTF-8・Shift_JIS（CP932）のTXTを選びます。Suno形式の `Lyrics:` より後を読み込みます。

## 自動同期する

画面右上の「同期を開始」を押します。処理の進捗とキャンセルも同じ場所から操作できます。同期候補の時刻・要確認理由・未配置を確認し、「候補をプレビューに適用」を押すと字幕を編集できます。

処理中に素材や同期用の歌詞を変更した場合は、最新の内容で同期をやり直します。既存の字幕に新しい候補を適用する操作は元に戻せます。

## 波形と字幕タイムライン

プレビューの「タイムライン」から、音声波形、再生位置、字幕を同じ目盛りで確認できます。波形をクリックするとシークします。同期候補をプレビューに適用して字幕を選択し、両端のハンドルをドラッグすると開始・終了を調整できます。ハンドルにフォーカスして左右の矢印を押すと50msずつ、Shiftを押しながら操作すると500msずつ移動します。隣の字幕とは重ならない範囲で調整されます。

## 字幕を編集する

「字幕編集」で再生位置への追加、文字と時刻の変更、削除、分割・結合ができます。未配置の行は開始・終了を入力するか、再生位置から配置します。「一括移動（秒）」は配置済みの全字幕に適用され、素材の範囲を超える場合は時刻の変更を保留します。

分割位置は再生位置で指定し、字幕の文字は時間の比率に応じて振り分けます。結合した字幕の元の行間は改行で残ります。タイムラインのドラッグと同期候補の適用も、1操作として元に戻す・やり直すことができます。

## 字幕スタイルと字幕ファイル

「字幕スタイル」でフォント、サイズ、文字色、不透明度、縁取り、影、文字間隔、行間隔、表示位置、フェードを調整できます。「字幕見本」で停止中も確認できます。

「字幕ファイル」で編集済みの字幕を保存します。SRTはUTF-8で時刻を1ms単位で保持します。ASSは1920×1080を基準とし、スタイルを含めて時刻を10ms単位に丸めます。丸めると表示区間がなくなる行は、時刻を調整してから保存します。未配置・本文が空の行がある場合は、対象から除くことを確認してから保存します。

ASSのフォントは再生するPCに同じ書体をインストールしてください。ブラウザと字幕プレイヤーの描画方式により、字形や太さに差が出る場合があります。SRTの空行は字幕の区切りに使われるため省きます。記号列を装飾として解釈するSRTプレイヤーもあります。そのような記号を文字として表示したい場合は、ASSをlibass対応の環境で使えます。

## 字幕付きMP4を書き出す

「MP4出力」で16:9（1920×1080）または9:16（1080×1920）を選ぶとプレビューの比率が変わります。MP4、またはMP3・WAVと背景画像を使えます。元映像と背景画像は縦横比を保ち、足りない部分を黒で埋めます。

「MP4を書き出す」を押すと、開始時の素材・字幕・スタイルを使ってFFmpegでH.264/AACのMP4を作成します。合成中は進捗を確認し、キャンセルできます。完了後にファイル名を確認して「MP4を保存」を押します。同名のファイルがある場合は、欄で名前を変更して保存できます。保存先や同名ファイルの扱いはブラウザの設定に従います。

書き出し用にPC内に一時ファイルを作ります。元素材を上書きする操作はありません。新しい書き出しをキャンセルした場合や失敗した場合も、直前に完成したMP4は保存できます。作業を終える前に完成したMP4を保存してください。

## プロジェクトを保存・復元する

「プロジェクト」で名前を入力して保存します。編集を止めると自動保存され、同じブラウザで開き直すと最後のプロジェクトを復元します。保存済みの別プロジェクトは一覧から開けます。複数の画面で同じプロジェクトを編集した場合は、先に保存した版が残り、未保存の編集は「別名で保存」で保持できます。

Windowsでは既定で `%LOCALAPPDATA%/LyricStudio` にプロジェクトJSONと同期結果を保存します。起動時に `--data-dir` を指定すると保存先を変更できます。保存内容には同期用歌詞、編集した字幕と時刻、スタイル、出力比率、素材名とSHA-256を含みます。再開時は元の動画・音声・背景画像を選んで再リンクします。移動・改名しても内容が同じファイルを選べます。Undo/Redoの履歴は編集中の画面に保持します。

自動同期は素材・歌詞・モデル・実行設定が一致する場合に、完了した結果を再利用します。途中でキャンセルした結果は保存しません。モデルの識別情報を取得できない場合は再解析します。

## 読み込みや書き出しに失敗したとき

| 表示・状態 | 確認すること |
| --- | --- |
| 同期を開始できない | 動画または音声、字幕に使う歌詞、起動時のsmallモデル指定を確認します。 |
| MP4の音声がない、または再生できない | 音声トラックと、EdgeまたはChromeで再生できるコーデックを確認します。 |
| ASSやMP4の短い字幕が保存できない | 表示区間が10ms刻みで確保できるよう、字幕の長さを調整します。 |
| 書き出しのフォントが見つからない | 「字幕スタイル」で現在のPCに入っているフォントを選びます。 |
| 保存が競合した | 「別名で保存」で編集を保持するか、保存済みの版を開き直します。 |
| CUDAで同期できない | ドライバーとDLLを確認します。CPUで実行するには、起動コマンドの `--device cuda` を外します。 |
